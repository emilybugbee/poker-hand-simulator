# poker-hand-simulator

A C++ program that models a virtual deck of cards, generates randomized poker hands, and identifies hand classifications.

## What I Built
- Implemented a custom vector data structure
- Used the vector to model and manipulate a virtual card deck
- Generated randomized five-card poker hands
- Implemented logic to classify poker hands

## Technologies
C++ · Data Structures · Algorithms · Vectors

## Course Context
Developed as a CS 20A course project at Santa Monica College. Project specifications and portions of the starter code/scaffolding were provided by my instructor, Nathan Greenfield. My implementation was completed as part of the assignment.
